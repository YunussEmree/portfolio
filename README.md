# Yunus Emre Şenyiğit — Portfolio

Personal site of **Yunus Emre Şenyiğit**, backend software engineer in Antalya, Türkiye.

**Live:** [yunusemresenyigit.dev](https://yunusemresenyigit.dev)

---

## Stack

| Layer | Tech |
|---|---|
| Framework | Next.js 15 (App Router, every page statically generated) |
| Styling | Tailwind CSS v4 (CSS-first tokens in `app/globals.css`) |
| Fonts | Geist, Geist Mono, Instrument Serif (`next/font`) |
| Motion | CSS transitions + IntersectionObserver (`components/reveal.tsx`), Lenis smooth scroll |
| Icons | lucide-react |

## Commands

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run start    # serve the production build
npm run cv       # print /cv to public/Yunus_Emre_Senyigit_CV.pdf (needs dev or start running; CV_URL to override)
```

## Editing content

Everything the site says comes from `data/`; components never hard-code content.

- **Headline:** `PROFILE.headline` — `|` starts a new line, `*text*` is set in the serif accent.
- **Metrics:** `METRICS` in `data/profile.ts`. Keep every number verifiable.
- **A new flagship project:** add it to `projects` in `data/projects.ts` with screenshots in `public/work/`
  (`shotKind: "phone"` for three 600×1067 portrait shots, `"browser"` for 1200×750 desktop shots) and a `tint` from
  the product's colors. It gets a card on the home page, a case study at `/work/<slug>`, a sitemap entry, a command
  menu entry and a line on the résumé.
- **Résumé:** after changing content, run `npm run cv` so the PDF matches the site.

## Theme

Dark by default, light on request; the choice is stored in `localStorage` and applied before the first paint. Colors
are CSS variables (`--bg`, `--fg`, `--muted`, `--faint`, `--accent`…) mapped to Tailwind names (`bg-bg`, `text-muted`,
`text-accent`…); change them in `app/globals.css` only. Small text colors meet WCAG AA in both themes.

## SEO

Per-page metadata, canonical URLs, Open Graph image, `ProfilePage`/`Person` structured data, sitemap and robots.
Set `NEXT_PUBLIC_SITE_URL` if the site moves to another domain.
